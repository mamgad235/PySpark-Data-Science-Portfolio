# PySpark Data Science & Machine Learning Portfolio

This repository contains a collection of data engineering and machine learning projects built using **Apache Spark (PySpark)**. The focus is on distributed data processing, exploratory data analysis (EDA), and scalable predictive modeling.

## 🛠️ Technology Stack
* **Framework:** Apache Spark (PySpark), PySpark MLlib
* **Languages:** Python
* **Data Structures:** Spark DataFrames, RDDs

---

## 📂 Featured Projects

### 1. [Employee Retention & Demographic Analysis](./01_Employee_Retention_Analysis/employee_retention_eda.ipynb)
An exploratory data analysis pipeline that processes human resources data to identify trends in employee turnover. 
* **Focus:** DataFrame operations, filtering, grouping, and statistical aggregations.

### 2. [Predictive Analytics: Performance Classification](./02_Student_Performance_Classification/student_performance_model.ipynb)
A machine learning pipeline designed to predict binary outcomes based on behavioral metrics.
* **Algorithm:** Logistic Regression
* **Focus:** Binary classification, model training, and accuracy evaluation (Achieved 100% accuracy on test data).

### 3. [Airbnb Market Pricing Model](./03_Airbnb_Pricing_Regression/airbnb_pricing_model.ipynb)
A regression model built to estimate real estate/rental prices based on property attributes, geographical data, and customer reviews.
* **Algorithm:** Linear Regression
* **Focus:** Feature engineering with `VectorAssembler`, RMSE, and R-Squared ($R^2$) metric evaluation (Achieved $R^2$ of 0.96).
